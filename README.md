# نَفَس — تطبيق إدارة يومك الشخصي

## محتويات المجلد
- `index.html` — التطبيق كاملًا في ملف واحد (يعمل بدون إنترنت)
- `manifest.webmanifest` — ملف التثبيت (الاسم، الأيقونة، الألوان)
- `sw.js` — يجعل التطبيق يعمل بدون إنترنت ويحدّث نفسه
- `icons/` — أيقونة التطبيق بكل المقاسات

## الرفع على GitHub (مرة واحدة)
1. ادخل github.com ← **New repository** ← سمّه `nafas` ← اختر **Public** ← Create.
2. اضغط **uploading an existing file** واسحب **كل محتويات هذا المجلد** (وليس المجلد نفسه) ← **Commit changes**.
3. من المستودع: **Settings ← Pages** ← Source: `Deploy from a branch` ← Branch: `main` / `(root)` ← Save.
4. بعد دقيقة يظهر الرابط: `https://اسم-حسابك.github.io/nafas/`

## التثبيت على الجوال
- **آيفون:** افتح الرابط في **Safari** ← زر المشاركة ← **إضافة إلى الشاشة الرئيسية**.
- **أندرويد:** افتح الرابط في **Chrome** ← القائمة ⋮ ← **تثبيت التطبيق**.

## التحديث لاحقًا
ارفع `index.html` الجديد مكان القديم في المستودع؛ يتحدّث التطبيق على جوالك عند فتحه وهو متصل بالإنترنت.

## ملاحظات
- كل بياناتك (الوجبات، المصاريف، الصور، جهات الطوارئ) محفوظة **على جوالك فقط**. استخدم «تصدير البيانات» من الإعدادات لأخذ نسخة احتياطية.
- لإبقاء المستودع خاصًا مع GitHub Pages تحتاج حساب GitHub Pro؛ المستودع العام لا يكشف بياناتك لأنها غير مرفوعة أصلًا.
- الملف المصدري القابل للتعديل هو `Nafas App.dc.html` في المشروع.
